# Project instructions

This project was built with the microsoft-foundry skill. Before working on or
answering questions about Foundry agents, read the microsoft-foundry skill first.

- Keep `COPILOT_MODEL` defaulted to `claude-opus-5`.
- Never commit GitHub or Azure credentials.
- Keep the hosted endpoint compatible with the Foundry invocations protocol.
- Prefer explicit tool allowlists; do not enable all Copilot CLI tools by default.
